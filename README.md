# Knowora

**Your knowledge. One intelligent conversation.**

Knowora is an AI-powered document assistant built with Retrieval-Augmented Generation (RAG). It lets users ask questions about a PDF knowledge base and receive answers generated from the most relevant passages in that document.

Instead of relying on general model knowledge, Knowora retrieves supporting content from the indexed document first. Each answer includes the retrieved source excerpts, their page numbers, and relevance scores.

**Live demo:** [knowora-la72.onrender.com](https://knowora-la72.onrender.com/)

> **Current knowledge base:** Knowora currently answers questions about Spring Boot, using the PDF included in this project as its source of truth. Questions outside that document's scope should be refused.

## What it does

- Extracts text from a PDF document.
- Splits the document into overlapping chunks and converts them into vector embeddings.
- Stores those embeddings in a local Qdrant vector database.
- Retrieves the most relevant passages for each user question.
- Uses Groq to produce concise, document-grounded answers with page citations.
- Provides a responsive chat interface with suggested prompts, source references, loading feedback, and error handling.
- Includes an evaluation script for factual, reasoning, and out-of-scope questions.

## How it works

```text
PDF document
    ↓
Text extraction and chunking
    ↓
Embeddings and local Qdrant index
    ↓
Question from the Knowora interface
    ↓
Relevant passages retrieved from Qdrant
    ↓
Grounded answer generated by Groq
```

## Technology

- **Backend:** FastAPI
- **Frontend:** HTML, CSS, and vanilla JavaScript
- **Vector search:** Qdrant local storage
- **Embeddings:** FastEmbed
- **PDF parsing:** PyMuPDF
- **LLM:** Groq
- **Containerization:** Docker and Docker Compose
- **Automation:** GitHub Actions and Render deployment configuration

## Run locally

1. Install the dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Add a `.env` file with your Groq API key:

   ```env
   GROQ_API_KEY=your_groq_api_key
   ```

3. Add the PDF knowledge base at `data/document.pdf`.

4. Build the document index:

   ```bash
   python -m app.ingest
   ```

5. Start the application:

   ```bash
   uvicorn app.main:app --reload --port 7860
   ```

Open `http://localhost:7860` in a browser.

## Project structure

```text
app/
  main.py          FastAPI application and API routes
  ingest.py        PDF extraction, chunking, and indexing
  retrieve.py      Vector retrieval from Qdrant
  generate.py      Grounded answer generation with Groq
  config.py        Environment configuration
  static/          Knowora web interface and branding assets
data/              Source documents
eval/              RAG evaluation questions and runner
tests/             Automated tests
```

## API

| Route | Method | Description |
|---|---|---|
| `/` | `GET` | Knowora web application |
| `/health` | `GET` | Basic service health check |
| `/ask` | `POST` | Ask a question about the indexed document |

Example request:

```json
{
  "question": "What is the default scope of a Spring bean?"
}
```

## Evaluation

The evaluation suite uses questions defined in `eval/questions.json` and measures retrieval, citations, answer quality, and refusal behavior for out-of-scope questions.

```bash
python eval/run_eval.py
```

## Current scope

Knowora currently indexes a single PDF knowledge base and provides a single conversational workspace. Document uploads, multi-document management, persistent conversation history, and authentication are future extensions.
